Car Dealership
Description
Car Dealership is a Java console application that allows dealership employees to manage vehicle inventory. Users can search for vehicles using multiple criteria, add vehicles, remove vehicles, and save inventory changes to a CSV file.

Features
Search By Price Range
Search By Make and Model
Search By Year Range
Search By Color
Search By Mileage Range
Search By Vehicle Type
List All Vehicles
Add Vehicle
Remove Vehicle
Save Inventory Changes To CSV
Technologies Used
Java
IntelliJ IDEA

How To Run
Open the project in IntelliJ IDEA.
Ensure inventory.csv is located in src/main/resources.
Run Main.java.
Use the dealership menu to search, add, remove, and manage inventory.
